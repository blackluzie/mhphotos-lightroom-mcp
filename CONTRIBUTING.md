# Contributing

Thank you for your interest! Please open an issue before substantial architectural changes.

- Use Python 3.11+ and keep changes small and tested.
- Do not commit photos, Lightroom catalogs, API tokens, machine-specific paths, or private metadata.
- Never introduce direct writes to Lightroom's SQLite catalog.
- Use test catalogs for integration tests.
- Document new tools and whether they modify user data.
- Be respectful in issues and pull requests.
